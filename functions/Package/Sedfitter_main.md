# **Sedfitter module**

`Sedfitter` is a Python-based software package that employs libraries of theoretical SED templates to fit observational photometric data. 
The original package was develop by Robitaille T. in 2007 and it is available in [astrofrog/sedfitter](https://github.com/astrofrog/sedfitter) in GitHub.

The package used in this workflow is an update version from Richardson T. in 2024, available in [richardson-t/sedfitter](https://github.com/richardson-t/sedfitter) also in GitHub. 
When directory is installed, change the folder name to *Sedfitter_main* and move it to the functions directory.
